# Security Policy

## Supported Versions

Currently, as this project is in active development, only the `main` branch is receiving security updates.

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < v1.0  | :x:                |

## Reporting a Vulnerability

We take the security of CampusEats seriously. If you discover a security vulnerability within this project, please do not disclose it publicly. 

Instead, please report it via [GitHub Security Advisories](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) if the feature is enabled for this repository. Alternatively, reach out directly to the repository maintainers.

Please include the following information in your report:
* The type of issue (e.g., buffer overflow, SQL injection, cross-site scripting, etc.)
* The location of the vulnerability in the source code (if known)
* The potential impact of the vulnerability
* Steps to reproduce the vulnerability

We will triage your report and provide a response addressing the issue within 48 hours.

## Disclosure Policy

When a vulnerability is reported, we will:
1. Confirm the issue.
2. Provide an estimated timeline for a fix.
3. Release a patch addressing the vulnerability.
4. If applicable, publish a security advisory detailing the issue and fix, giving credit to the reporter if desired.
